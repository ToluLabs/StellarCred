Canonical Integration Reference

StellarCred Integration Flow

Complete reference application demonstrating wallet-control proof, on-chain re-verification, route gating, and failure state diagnostics.

1 Redirect to Verify (buildVerifyUrl)

Generate the StellarCred verification link to redirect unverified users so they can generate and submit their ZK proof.

2 Return Redirect & Untrusted Hint (parseReturnParams)

⚠️ Crucial Security Principle: URL parameters like ?sc_verified=true&sc_wallet=G... returned from redirects are untrusted client hints. Anyone can construct a URL containing another person's verified wallet address. Never grant access or issue session tokens based on URL hints alone.

3 & 4 Prove Wallet Control & Verify On-Chain (verifyWalletClaim)

The server generates a replay-protected challenge. The client signs it with their wallet (Ed25519), and the server verifies both wallet control AND on-chain claim status atomically.

5 Gated Route: Protected Treasury

Access sensitive server-side endpoints conditioned on an active, authenticated session.

6 Failure State & Attack Simulator

Verify that the application properly detects and defends against attacks and failure states.
