    Optionalsource

    source?: ClaimSource

    Where to read from. Defaults to "chain".

    ⚠️ "indexer" reads come from an operator-run off-chain cache, not from ProofRegistry. They are faster but can be stale or wrong, and must not be the sole basis for a security decision — gate-critical checks should use "chain", or "indexer-verified" to keep the chain as the authority. Requires indexerUrl to be configured. See ClaimSource.
