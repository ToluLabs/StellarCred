    Function buildVerifyUrl

    • buildVerifyUrl(opts: BuildVerifyUrlOptions): string

      Builds a strongly typed StellarCred verification redirect URL.

      Redirecting an unverified user to this URL opens the StellarCred verification flow. After verifying (or cancelling), StellarCred redirects back to returnUrl with query parameters:

      • sc_verified: "true" if verification succeeded
      • sc_wallet: The holder's wallet address
      • sc_claims: Comma-separated list of claim types issued in this session
      • sc_state: Roundtrips the state parameter if supplied

      ⚠️ SECURITY NOTICE: Parameters in the redirect URL are UNTRUSTED HINTS. Anyone can construct a URL with arbitrary parameters. Always verify wallet control via challenge signature and confirm on-chain credentials via hasClaim / verifyWalletClaim before granting access.

      Parameters

      • opts: BuildVerifyUrlOptions

        Verification redirect URL options

      Returns string

      The fully constructed verification URL string

      Throws

      If returnUrl is missing or empty.

      Throws

      If expiresInMinutes is not a positive finite number.

      Throws

      If singleUse is true but no crypto implementation is available.

      Example

      // Basic KYC redirect
      const url = buildVerifyUrl({
        returnUrl: "https://yourapp.xyz/dashboard",
        claim: "kyc",
      });

      Example

      // Age verification requiring 21+
      const url = buildVerifyUrl({
        returnUrl: "https://yourapp.xyz/app",
        claim: "age",
        claimParams: { threshold_years: 21 },
      });

      Example

      // Funds verification requiring >= $50,000 balance
      const url = buildVerifyUrl({
        returnUrl: "https://yourapp.xyz/vault",
        claim: "funds",
        claimParams: { threshold: 50_000 },
      });

      Example

      // Jurisdiction gate blocking specific ISO 3166-1 numeric country codes
      const url = buildVerifyUrl({
        returnUrl: "https://yourapp.xyz/trade",
        claim: "jurisdiction",
        claimParams: { restricted: ["840", "364"] },
      });

      Example

      // Single-use, time-limited verification link
      const url = buildVerifyUrl({
        returnUrl: "https://yourapp.xyz/callback",
        claim: "kyc",
        expiresInMinutes: 15,
        singleUse: true,
        state: "sess_xyz123",
      });
