    Class MockProofRegistry

    In-memory ProofRegistry. Reads follow the contract exactly: a proof counts only while it is unrevoked and expiry is after the ledger time, a trusted_issuers list rejects other issuers (and proofs with no issuer), and check_claim compares the stored threshold against min_threshold.
