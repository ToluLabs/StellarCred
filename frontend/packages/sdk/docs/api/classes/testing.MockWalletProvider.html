    Class MockWalletProvider

    An in-process wallet with the SEP-43 surface (getAddress, signMessage, signTransaction) that Stellar Wallets Kit modules expose, backed by a real Ed25519 keypair. Use it wherever your integration takes a wallet.

    signMessage signs the UTF-8 bytes of the message directly, which is what verifyWalletSignature and verifyWalletClaim check.
